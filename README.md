# Financial Report

Веб-приложение для автоматизации работы с финансовыми отчётами **Wildberries**.

Проект создан, чтобы заменить ежедневную ручную расшифровку и подсчёт отчётов реализации на удобный автоматизированный инструмент.

---

## Возможности

- Загрузка финансовых отчётов Wildberries (XLSX / ZIP)
- Автоматическая расшифровка и нормализация данных
- Расчёт себестоимости и прибыли по каждому SKU
- Управление дополнительными расходами
- Хранение фотографий товаров
- Дерево отчётных периодов
- Экспорт отчётов в XLSX и ZIP
- Отслеживание статуса загрузки отчётов
- Работа с токенами Wildberries API
- Настройка налоговых параметров
- Режим расшифровки отчёта без регистрации
- Админ-панель
- Фоновая обработка задач через очередь

---

## Стек технологий

**Backend:**

- Node.js (ES Modules)
- Express 5
- MongoDB + Mongoose (с client-side encryption)
- RabbitMQ
- AWS S3
- JWT (jose) + Argon2
- Joi (валидация)
- ExcelJS(community) + JSZip
- Pino (логирование)
- Multer

**Frontend:**

- Vanilla JavaScript (модульная архитектура)
- HTML / CSS

**Инфраструктура:**

- Docker + Docker Compose
- Nginx (reverse proxy + SSL)
- MongoDB Crypt Shared Library
