Расшифровка финансового отчёта Wildberries

Загрузите отчёт WB — получите понятную таблицу с расшифровкой SKU, расходами и итогами. Бесплатно, локально, файлы не покидают эту страницу.

Что вы получите

  • Расшифровку всех SKU из отчёта Wildberries
  • Расчёт расходов, удержаний и комиссий
  • Итоговые суммы по отчёту
  • Возможность скачать результат в Excel

Как это работает

  1. Нажмите «Загрузите ваши отчеты»
  2. Загрузите файл отчёта WB
  3. Получите таблицу с расшифровкой
  4. Скачайте результат в Excel с формулами
    с возможность указать себестоимость
