1

WB реализовал

Разница между суммой продаж и суммой возвратов по данным Wildberries.

WB реализовал = «Вайлдберриз реализовал Товар (Пр)» (Продажа) − «Вайлдберриз реализовал Товар (Пр)» (Возврат)
2

Налогооблагаемая база

Показатель зависит от типа отчёта за период.

Только отчёт «Основной» Налогооблагаемая база = «Вайлдберриз реализовал Товар (Пр)» (Продажа) − «Вайлдберриз реализовал Товар (Пр)» (Возврат)
Только отчёт «По выкупам» Налогооблагаемая база = «К перечислению продавцу за реализованный товар» − «Стоимость логистики товара»
Оба типа отчётов Налогооблагаемая база = (расчёт по «Основному») + (расчёт по «По выкупам»)
3

Продано

Количество товаров с типом документа «Продажа».

4

Возвраты

Количество товаров с типом документа «Возврат».

5

Перечисления продавцу

Сумма по столбцу «К перечислению Продавцу за реализованный Товар» в детализации.

Перечисления продавцу = сумма по документам «Продажа» − сумма по документам «Возврат»
6

Себестоимость товаров

Суммарная себестоимость проданных товаров.

Себестоимость товаров = Σ (себестоимость единицы × количество проданных единиц)

Суммирование ведётся по всем товарным позициям отчёта.

7

Прочие расходы

Сумма прочих расходов по каждой позиции с последующим суммированием по всем позициям.

Прочие расходы = Σ (прочие расходы по позиции)
8

Доставка

Сумма всех значений поля «Стоимость доставки».

9

Приёмка

Сумма всех значений поля «Стоимость операций при приёмке».

10

Штрафы

Сумма к оплате по всем видам полученных штрафов по всем позициям.

11

Удержания / выплаты

Сумма прочих удержаний и выплат по всем позициям.

12

Хранение

Для расчёта суммы за хранение по каждому товару запрашивается отдельный отчёт «О платном хранении» за тот же отчётный период.

13

Реклама

На текущий момент расходы на рекламу нельзя отнести к каждой единице товара, поэтому рассчитывается среднее значение на одну позицию.

Реклама = (все рекламные расходы за отчётный период) / (количество позиций)

где количество позиций — не количество единиц товара.

i Источник данных — отчёт «Получение истории затрат» за отчётный период.
14

Налоги

При добавлении суммы налога в отчет, сумма распределяется равномерно между позициями.

15

Страховые взносы

При добавлении суммы страховых взновов в отчет, сумма распределяется равномерно между позициями.

16

Доп. страховые взносы

При добавлении суммы доп. страховых взновов в отчет, сумма распределяется равномерно между позициями.

17

Итого

Итого = Перечисления продавцу − Штрафы − Приёмка − Удержания/Выплаты − Реклама − Хранение − Доставка − Себестоимость − Прочие расходы − Налоги − Страховые взносы − Доп. страховые взносы
18

Маржинальность

Маржинальность = (Итого × 100) / WB реализовал
